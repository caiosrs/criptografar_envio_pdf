# 🛡️ Protetor de PDFs - Informatec

Aplicativo desktop em Python para proteger arquivos PDF com senha e enviá-los automaticamente por e-mail, com base em dados de um arquivo CSV.

## 🚀 Como usar

1. **Pré-requisitos**:
   - Python 3.8+
   - Instale as dependências com:
     ```bash
     pip install pikepdf PyPDF2
     ```

2. **Execute o script**:
   ```bash
   python criptografar_pdfs.py
